## Eval reference: AirCaps A5S Async v1 (cloud)

- Role: eval reference (paid, cloud). Would replace AssemblyAI Universal-3.5 Pro.
- What it is: a batch speech-to-text API from AirCaps AI, a company that makes live captioning products, released in early November 2026. It returns one transcript with speaker labels and word timestamps for a whole recording; speaker labels are always on. AirCaps does not say how it is built.
- Claimed numbers:
  - Voice Arena Diarization Bench, Diarization + ASR track, English ([leaderboard](https://voicearena.com/diarization-bench), independent, 139 sessions, 272,690 words): rank 1, cpWER 23.89% (95% CI 19.47–28.58) against 47.81% (43.25–52.48) for AssemblyAI Universal-3.6 Pro at rank 8. cpWER counts a word under the wrong speaker as an error. Most of AssemblyAI's errors there are deletions (37.25 points against 9.29 for A5S). Universal-3.5 Pro, the model we use, is not on that board. A5S has no row on Voice Arena's US English STT board.
  - AirCaps' own benchmark ([repo](https://github.com/aircaps/a5s-async-v1-benchmark), vendor-run, raw responses published, AirCaps run 2026-11-06, others 2026-11-01/02): cpWER on AMI (single distant mic) 15.83 against 25.80 for Universal-3.5 Pro; NOTSOFAR-1 16.65 against 34.10; single-speaker clips (VoxPopuli, LibriSpeech, Earnings-22) mean 6.28 against 6.33. So the gain is in who-said-what on meetings, not in plain word accuracy.
  - Training data is not disclosed, so whether AMI is held out cannot be checked. The Voice Arena number does not rest on AMI.
- Price and model id: $0.18 per audio hour after 5 free hours; model id `a5s-async-v1`. Files up to 3 hours or 5 GB in one job, so a 1-hour meeting goes in one request.
- Data use: on the free tier, uploads are used for model training with no opt-out. A paid account can opt out in the console. Add credits and opt out before sending any meeting or dictation audio. Transcripts are kept 30 days by default (paid accounts can set 1 hour to 30 days).
- Provenance: GitHub org [aircaps](https://github.com/aircaps) (created 2024-09-26, 3 public repos); the benchmark repo was created and last pushed 2026-11-07, MIT, 2 stars. Announced on r/speechtech by an AirCaps employee. Docs at [aircaps.ai/docs](https://aircaps.ai/docs/index.md).
- Who uses it: `gh search code "a5s-async-v1"` finds only an API catalogue (jentic/jentic-public-apis). Too new to have users.
- Eval to run: the eval-reference check from the skill. Add an `aircaps.py` beside `Scripts/asr-eval/assemblyai.py`, run it on the 12 meeting tracks and 50 dictations, then have the user judge the spans where it and Universal-3.5 Pro disagree (`listen-review` skill). Also compare its speaker labels with AssemblyAI's on the wrong-speaker word rate (`make asr-eval ARGS=score`), since speaker attribution is where its numbers are strongest.
