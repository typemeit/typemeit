## Speech recognition: Phonon ASR (Parakeet TDT 0.6B v2 + N8avg, int8 ONNX)

- Role: speech recognition, dictation first. Would replace FluidAudio Parakeet Ultra.
- What it is: the speech model of Phonon, an open-source voice-typing app. It is NVIDIA's Parakeet TDT 0.6B v2 with a rank-16 LoRA merged into all 24 encoder layers (the mean of two training seeds), trained with a second talker mixed in at 0 to 15 dB, background noise, room echo and 30 to 75 s clips. The decoder and joiner are unchanged.
- Claimed numbers, against stock Parakeet TDT 0.6B v2 in NeMo, with paired-bootstrap 95% intervals ([card](https://huggingface.co/Infatoshi/phonon-asr-parakeet-tdt-0.6b-v2-onnx)): SVQ with background speech 25.58 → 13.58 (−12.00), SVQ clean −0.35, Med-Dictate 60 s windows −1.29, AppTek −0.40, Earnings-25 −0.20, EdAcc −0.10 (interval crosses zero). The int8 export scores 18.02 against 18.52 for the stock int8 export on 578 private dictation clips the model did not train on. EdAcc is in its training data, so that row is not held out; SVQ, Med-Dictate, AppTek and Earnings-25 are not in the listed training sets. The baseline is v2, not Ultra, so the gain over what we ship is unknown.
- Licence and size: CC-BY-SA-4.0 (flag: EdAcc in the training data carries share-alike, so a Core ML build we mirror would carry it too; read the licence terms before a trial). int8 ONNX, 661 MB in five files (encoder 652 MB).
- Provenance: published by Hugging Face user Infatoshi, maker of [Infatoshi/phonon](https://github.com/Infatoshi/phonon) ("Fast, local, simple voice typing for macOS", GPL-3.0, 378 stars, created 2026-07-21, pushed 2026-11-09). Card created and last updated 2026-11-09, 0 downloads and 0 likes so far. Built on nvidia/parakeet-tdt-0.6b-v2 (CC-BY-4.0) with the sherpa-onnx export recipe. The same maker's Phonon refiner 1.7B was rejected for clean-up on 2026-11-06; that was a different model and role.
- Who uses it: the Phonon app itself. A code search finds no other project yet.
- Expected gain and risk: the mixed-in second talker targets the same thing as Fluid Speech Mini, which tied on dictation and lost words on room tracks (rejected 2026-10-17). Expect a dictation tie or small gain, and watch deletions on room and others tracks.
- Eval to run: `make asr-eval` with `--like fluid-ultra`, on dictation and meeting tracks, reading S/D/I per track type. No adapter loads sherpa-onnx yet: add `Scripts/asr-eval/systems/phonon_asr.py`, copying `granite_nar.py`, with `sherpa_onnx.OfflineRecognizer.from_transducer(..., model_type="nemo_transducer")` and 60 s passes as the card describes. Shipping would need a Core ML conversion (FluidAudio loads v2-layout TDT bundles).
