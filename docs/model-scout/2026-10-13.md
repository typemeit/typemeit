# Model scout 2026-10-13

Parakeet release check: FluidAudio 0.17.6 and 0.17.7 (newer than our 0.17.5 pin) add Kokoro ANE and Paradee-8M text-to-speech only; no new speech or diarization model.

## MOSS-Transcribe-Diarize 0.9B

- Role: meetings. One model that transcribes and labels speakers in a single pass, so it would replace Parakeet Ultra plus Nemotron 3 Diarization for calls. Not a dictation candidate.
- Claimed numbers: Open ASR Leaderboard average WER 6.29 against 6.43 for parakeet-tdt-0.6b-v2 (RTFx 387 against 6148, on the leaderboard's GPU). First place in the 2nd MLC-SLM Challenge (cpCER, multi-speaker). No DER or AMI WER published. [Leaderboard rows](https://datasets-server.huggingface.co/rows?dataset=hf-audio/open-asr-leaderboard-results&config=default&split=train&offset=0&length=100), [model card](https://huggingface.co/OpenMOSS-Team/MOSS-Transcribe-Diarize).
- Licence and size: Apache-2.0, 0.91B parameters. MLX 4-bit and 8-bit ([vanch007](https://huggingface.co/vanch007/mlx-MOSS-Transcribe-Diarize-4bit)) and GGUF conversions exist; the weights are from 2026-07-09, so it is outside the 7-day window and is here because its leaderboard row is new to us.
- Eval to run: `make asr-eval` for WER (add the candidate as one file in `Scripts/asr-eval/systems/`), plus `make asr-eval ARGS=score` for wrong-speaker words against AssemblyAI labels; the Nemotron baseline adapter there is still a stub, so build it first. Budgets to check: 90-minute single pass at 5x realtime or better and 6 GB peak.

## Orukeet (oruk/orukeet)

- Role: dictation and meetings speech recognition. Would replace Parakeet Ultra. Same architecture as Ultra (a Parakeet TDT 0.6B v3 fine-tune), so it loads through the same TDT code path.
- Claimed numbers: against Parakeet TDT v3 (not Ultra), LibriSpeech test-clean 1.46% vs 1.53%, test-other 2.86% vs 3.14%, FLEURS English 3.82% vs 4.28%, 20 English accent/domain splits 8.84% vs 9.51%; better on 61 of 74 splits. NeMo greedy decode, FP32, scored with the authors' own normaliser. Ultra's gain over v3 is not in these tables, so the real margin over what we ship is unknown. [Model card](https://github.com/Oruk-AI/orukeet/blob/main/MODEL_CARD.md), [weights](https://huggingface.co/oruk/orukeet).
- Licence and size: weights are CC-BY-SA-4.0 (share-alike; read `LICENSE-WEIGHTS` before mirroring them the way `ModelStore.swift` mirrors ours), code MIT. 25 languages, English results are the ones above. Core ML bundles for Apple Silicon (FluidAudio 0.15.5 loader, a peak compile size of about 1.82 GB), ONNX INT8 and a native Metal runtime exist. Already shipped in OpenWhispr 1.10.0 and TapTalk 0.4.0.
- Eval to run: `make asr-eval` dictation clips (50 clips, shipped 4.09% WER) and 12 meeting tracks (shipped 12.55% after listen review), as one file in `Scripts/asr-eval/systems/`. Check p95 against 97 ms and resident memory against 310 MB.
- Source: [r/speechtech, 2026-09-11](https://www.reddit.com/r/speechtech/), found in the review of the last five months below.

## Near misses

- bosonai/higgs-audio-v3-stt (6.19 average, 2.7B): no Apple Silicon build at this size, and the card says AMI train splits were in the fine-tuning data, so its AMI WER does not compare.
- Edge0/ARK-ASR-0.6B (6.29 average, 1.15B, 19 languages): 0.14 points ahead on the average, which is inside the 0.2-point tie, and no Core ML or MLX build.
- Qwen/Qwen3-ASR-1.7B (5.75 average): same architecture as Qwen3-ASR-0.6B, which is rejected in `docs/model-trials.md`.
- FluidInference/parakeet-redux-coreml (0.17.5 can load it, never tried): its own card puts it 0.44 (clean) and 1.00 (other) LibriSpeech points behind v3, the same accuracy gap that rejected Phonon-2.
- rewayai/suplime and suplime-large (diarization, pyannote 4.x, 114M and 349M, macro DER 15.86 against 16.06 for pyannoteAI precision-2): CC-BY-NC-4.0 weights, so it cannot ship. An independent clinical test on the same subreddit (Omi, 15 consultations, DER) had Nemotron 3 at 4.8% against Pyannote Community-1 6.6% and Sortformer v2.1 8.0%, which agrees with ours; it did not include MOSS or SUPlime.
- Cactus-Compute/whistle (16.9 MB, English plus six languages): compared only against Whisper and Moonshine, not Parakeet.
- FoxNoseTech/diarize (CPU-only, DER 10.8% on VoxConverse against 11.2% for pyannote free models): behind Nemotron 3.
- NVIDIA RE-USE speech enhancement (SpeechLens, MLX): enhancement, not a role we ship a model for; enhancement before ASR usually costs accuracy.
- speech-swift LocalVQE echo cancellation: the same model as our LocalVQE trial.
- Mega-ASR (Qwen3-ASR retrain): no weights or repository linked; Qwen3-ASR-0.6B is already rejected.
- Krisp voice isolation benchmark: a proprietary model.
- LiquidAI/LFM2.5-24B-A2B (clean-up): 24B parameters, over the memory budget; LFM2.5-8B-A1B is already rejected.
- HojoAI/Hojo-ASR-V1 (6.07 average): 5.2B parameters.
- TheStageAI/thewhisper-large-v3-turbo (6.07 average): Whisper family, built for NVIDIA GPUs.
- reson8/resonant-1-flash, sophea/asr-k1, meta/muse-voice-transcribe, zoom/scribe, elevenlabs/scribe_v2, microsoft/azure-speech, openai/gpt-transcribe: proprietary, cloud only.
- ibm-granite/granite-speech-5.0-470m-turboctc-nc: Granite 5.0 is rejected, and the best variant is non-commercial.
- FluidInference/clef-text-0.6b-coreml, d1/d3 classifiers, embeddinggemma-2-coreml, Paradee-8M: not a role we ship a model for.
- Pashted FastConformer GGUFs (be, ka, hy), onnx-community Whisper and Voxtral fine-tunes: not English.
