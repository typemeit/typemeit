## Eval reference: Zoom Scribe v2.1 Pro (meetings)

- Role: eval reference for meetings. Would replace AssemblyAI Universal-3.5 Pro.
- What it is: an update of Zoom's paid speech-to-text API, the version after Scribe v2 Pro, which the 2026-10-17 scout picked. It is a cloud model called through Zoom's AI Services API.
- Claimed numbers, run by the Open ASR Leaderboard maintainers with an API key Zoom gave them (leaderboard PR #256, opened 2026-10-23, merged 2026-10-30; joined the 02-11-2026 version): AMI-Cleaned 5.96 against 10.63 for Universal-3.5 Pro, private conversational 11.61 against 12.80, and average 4.87 against 6.23. It replaces v2 Pro (AMI 6.08, private conversational 12.10) in first place, ahead of Otter speech-v3.1 (6.42 / 12.01). The private sets are held out: the PR confirms Zoom does not train on or keep the audio. AMI is public, so whether AMI is in Zoom's training data is unknown.
- Price and model id: $0.20 an hour (entry price in the PR), and the model id is `zoom-scribe-en-pro-v2.1`, sent as `config.model` (the leaderboard's [zoom_provider.py](https://github.com/huggingface/open_asr_leaderboard/blob/main/api/providers/zoom_provider.py)). The request limits found on 2026-10-17 still apply: at most 100 MB and 2 hours per request, so a 1-hour track goes as FLAC or MP3, and speaker labels and word timestamps are documented.
- Provenance: Zoom Communications. Scribe v1 joined the leaderboard on 2026-04-09, v2 Pro on 2026-09-04, and v2.1 Pro in the 02-11-2026 version. Zoom's developer changelog has no entry for v2.1. Its last AI Services entries are 2026-10-15 (the `model` field) and 2026-11-02 (vocabulary fields for speech summarization).
- Who uses it: the leaderboard's harness, and cekura-ai/cekura-bench, a voice-agent benchmark.
- Eval to run: transcribe the 12 meeting tracks, then have the user judge the spans where it and Universal-3.5 Pro disagree (`listen-review` skill). Universal-3.5 Pro still ranks 11th on AMI-Cleaned, so the gap that made v2 Pro a pick is now 0.12 points wider.

## Speaker embeddings: TitaNet-Large (Core ML port)

- Role: speaker embeddings (the WeSpeaker 256-d embedder in FluidAudio's offline pipeline, used by `Diarizer.voice(of:)`, `SpeakerMerge` and `RoomVoices`). It could only replace WeSpeaker where the app embeds known spans itself. Inside FluidAudio's VBx clustering, WeSpeaker stays.
- What it is: NVIDIA's speaker-verification model from 2022 (23M parameters, 192-d embedding, trained on VoxCeleb 1 and 2 dev, Fisher, Switchboard, LibriSpeech and NIST SRE), now converted to Core ML. The port appeared 2026-10-30, which is why it counts again under the "gained an Apple Silicon build" rule. It sweeps a 5.12 s window across a clip and rebuilds the model's global statistics exactly, so any clip length works.
- Claimed numbers: NVIDIA reports 0.66% EER on cleaned VoxCeleb1 trials (VoxCeleb1 test is held out of its training). The port was not re-scored on that benchmark. It matches NeMo's embeddings to cosine 0.9999999994 in fp32 and 0.9968 at worst in fp16 on the Neural Engine, over 40 VoxCeleb1-test clips. WeSpeaker's published ResNet34 result on the same trials is about 0.72%, so the expected gain is small. [Port card](https://huggingface.co/smdesai/TitaNet-Large-CoreML), [NVIDIA card](https://huggingface.co/nvidia/speakerverification_en_titanet_large).
- Licence and size: CC-BY-4.0. fp32 is 88.5 MB (GPU/CPU), fp16c is 46.7 MB (Neural Engine). A 65 s clip takes 0.22 s on the Neural Engine on an iPhone, with 95 MB peak memory.
- Provenance: NVIDIA (NeMo). The original card was created 2022-07-15 and last updated 2023-11-14, with 106,854 downloads and 137 likes. The Core ML port is by an individual Hugging Face user, created and last updated 2026-10-30, with 38 downloads and 0 likes. The same user publishes a Core AI build for macOS 27 and a Core AI build of parakeet-unified. Another Core ML port (nikioth/titanet-large-coreml) appeared the same day.
- Who uses it: TitaNet itself appears in NVIDIA-NeMo/Curator, deeeed/audiolab and several small meeting-assistant repos. A code search finds no Swift project using either Core ML port yet.
- Eval to run: no eval exists. The `docs/voice-names-research/` scripts are ad hoc. Build an EER and voice-name accuracy check over the 12 meeting tracks' speaker turns, then compare WeSpeaker (FluidAudio) against TitaNet fp16c. It is worth doing only if voice-name matching is a known weak spot. The VoxCeleb gain is within what a different test set can reverse.

## FluidAudio 0.18.2

These changes touch code the app runs, so upgrading should be its own trial:

- #1056 and #1061: long-form v3-family decoding (Parakeet Ultra in meetings) now probes the span before the first token, and every gap between words, for dropped speech. Two public Earnings-22 windows lost their opening speech on 0.17.7. Hypothesis: a few fewer deletions on the meeting tracks. Measure with `make asr-eval ARGS="run shipped"` on the 12 tracks before and after.
- #1081: `OfflineDiarizerConfig()` now keeps overlapping speech by default (`exclusiveSegments: false`). `Diarizer.configuration` takes the default, so its segments change on upgrade. The embedder runs with exactly one speaker, where overlap cannot arise, but the S3 comparison probe and `MeetingProbes` sweeps would change. Set `exclusiveSegments: true` explicitly to keep today's behaviour, or measure the change.
- #1090: an interrupted model download now resumes instead of deleting the repo folder. This matters only if `ModelStore` downloads go through `ModelHub`.
- #1041, #1088, #1100: vocabulary boosting no longer swaps confidently heard common words, duplicates names or drops possessives. The app does not run vocabulary boosting (rejected 2026-09-26 and 2026-10-12, for exactly these wrong swaps). #1100 fixes the failure that trial rejected, so a re-trial of CTC boosting for custom words is now worth a hypothesis.
- #1091 (Sortformer), #1097 and #1035 (streaming): paths the app does not use.

## Near misses

- LiquidAI/LFM3-Audio-2B, and FluidAudio's `lfm3Audio` Core ML build (2026-10-29): a 2B audio language model whose card gives an English average of 6.23 on the older ESB suite, where parakeet-tdt-0.6b-v2 published 6.05. It would lose to Ultra on accuracy. Its LFM Open License requires a separate licence above $10M yearly revenue.
- LiquidAI/LFM3-Omni-2B, LiquidAI/d1-Omni-2B: omni models with no ASR number against Parakeet, and the same LFM licence.
- nvidia/nemotron-labs-unified-asr-0.6b, and FluidAudio's `nemotronUnified` (2026-10-28): the multilingual version of parakeet-unified-en-0.6b, the same architecture, which was rejected on 2026-10-12 (meetings 11.32% vs 10.90%). Its AMI 7.91 comes from training on Granary, which includes AMI.
- FluidAudio `phonon25` (Muesli-HQ/phonon-2.5-coreml): Phonon-2.5 was seen 2026-10-24. This build is the multilingual one, and Phonon-2 was rejected 2026-10-11.
- FluidAudio `bark3`, `bark3Clean`: Bark 3.0 was rejected on 2026-10-22. Clean drops words by design.
- FluidAudio `nemotron35TranscribeLite`: seen 2026-10-29.
- maya-research/maya-transcribe: a fine-tune of Qwen3-ASR-0.6B, which was rejected 2026-10-12, tuned for Hindi-English code-switching.
- EphAsad/SatellaSTT-27M: a Moonshine-tiny fine-tune for lab vocabulary. Its LibriSpeech WER is 6.91, worse than its base model's 5.00.
- WhissleAI/arc-v1.1: CC-BY-NC-4.0.
- nikioth/diarizen-wavlm-large-s80-md-v2-coreml, nikioth/diarizen-wavlm-base-s80-md-coreml: Core ML ports of DiariZen, which is CC-BY-NC-4.0.
- diarizeapp/redimnet2-b3-onnx: a speaker embedder whose card has no EER.
- fonada/kapture-v3 (eval reference): a new leaderboard row, but it is behind Zoom on AMI-Cleaned (7.91 vs 5.96) and private conversational (13.56 vs 11.61). It is built for Indic languages.
- category271/whispernow-lfm3-1.7b, category271/whispernow-nemotron-bolt-e4b: dictation clean-up models scored only against cloud models. Earlier WhisperNow builds were near misses on 2026-10-27, and LFM2.5-1.2B, a model of the same family, failed 64 more eval cases than Apple's model on 2026-09-25.
- hasanchadaram/dictation-cleanup-qwen3.5-4b-gguf: the card reports training loss only, with no held-out score.
- devadathanmb/utter-dictation-cleanup-qwen3-1.7b-mlx-6bit: an MLX port of utter-dictation-cleanup (seen 2026-10-27), with no score.
- danielrosehill/S1-ASR-Cleanup: an S1-mini fine-tune (S1-mini rejected 2026-09-25) under the S1-mini licence, with no score.
- Glimpse-Dictation/Glimpse-C1-2B: its licence forbids shipping the adapter in another product.
- Muesli-HQ/qwen35-2b-base-cotypist-mlx-4bit, Muesli-HQ/qwen35-0.8b-base-cotypist-mlx-4bit: autocomplete models, not a role we ship, and no score.
