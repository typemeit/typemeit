Parakeet release check: FluidAudio v0.17.6 and v0.17.7 are newer than the 0.17.5 pin; both add text-to-speech only (Kokoro ANE v3, Paradee-8M). Untried models the pinned version can load are listed under Near misses.

## ARK-ASR-0.6B

- Role: speech recognition, meetings first. Would replace FluidAudio Parakeet Ultra.
- Claimed numbers: Open ASR Leaderboard average WER 6.29 against 6.43 for parakeet-tdt-0.6b-v2; AMI-Cleaned WER 8.61 against 9.09. RTFx 673 against 6148 (about 9.1× slower on the leaderboard's GPU). [Leaderboard rows](https://datasets-server.huggingface.co/rows?dataset=hf-audio/open-asr-leaderboard-results&config=default&split=train&offset=0&length=100), [model](https://huggingface.co/Edge0/ARK-ASR-0.6B), paper arXiv 2605.28139. The leaderboard row is new to `seen.json`; the model dates from 2026-05.
- Licence and size: Apache-2.0, 1.15B parameters in the leaderboard row. Community MLX (`leope/ark-asr-0.6B-mlx`, 2.3 GB) and int8 ONNX (`Edge0/ark-asr-0.6b-int8-onnx`, 1.8 GB) builds exist; both are over the 1.5 GB file budget until quantised further.
- Provenance: published 2026-05-25 by AutoArk (GitHub org `AutoArk`, created 2025-08, no stated affiliation) as `Edge0/ARK-ASR-0.6B`; last updated 2026-06-27. Training and inference code in [AutoArk/open-audio-opd](https://github.com/AutoArk/open-audio-opd) (1.1k stars). Whisper-style encoder plus a Qwen2 0.6B decoder, trained by on-policy distillation; it is an LLM-decoder ASR like the rejected Qwen3-ASR-0.6B, but a different architecture. 850 downloads, 57 likes; a 3B sibling exists.
- Used by: code search finds references in SubtitleEdit (14.5k stars), voicebox (57k), pyvideotrans (19k), sglang-omni and CrispASR. Community GGUF, MLX and ONNX ports exist; no Core ML build of the 0.6B.
- Eval to run: `make asr-eval` (Scripts/asr-eval); add the candidate as one file in `systems/`. Speed and file size will likely reject it even if WER ties, so state that in the hypothesis.

## Near misses

- Parakeet Redux (FluidAudio `AsrModelVersion.redux`, untried in the pinned version): LibriSpeech test-clean 2.71% against Ultra 2.13%; accuracy lower, wins only on download (~220 MB). [Release notes](https://github.com/FluidInference/FluidAudio/releases/tag/v0.17.3).
- Parakeet v2 and v3, TDT-CTC-110m, CTC-0.6b, EOU-120m (FluidAudio, untried): v3 is the model Ultra was post-trained from and Ultra beats it on every published row; the others publish no number against Ultra.
- Nemotron streaming 0.6b (FluidAudio, untried): leaderboard average 6.89 against 6.43; accuracy lower.
- Canary 1B v2 (FluidAudio, untried): average 7.91; accuracy lower and 1B parameters.
- Cohere Transcribe Core ML q8 (FluidAudio): same architecture as the rejected Cohere Transcribe in `model-trials.md`.
- Sortformer (FluidAudio, untried by trial): capped at 4 speakers and unstable on long files per `docs/meetings.md`.
- Hojo-ASR-V1: average 6.07, AMI-Cleaned 7.54, Apache-2.0; 5.18B parameters, over the file and memory budgets.
- bosonai/higgs-audio-v3-stt: average 6.19, AMI-Cleaned 7.19; 2.68B parameters, over the file budget.
- Qwen3-ASR-1.7B: average 5.75; same architecture as the rejected Qwen3-ASR-0.6B, 1.7B parameters.
- TheStageAI/thewhisper-large-v3-turbo: average 6.07, AMI-Cleaned 7.32; weights are encrypted and load only through TheStage's SDK with an online API token.
- ibm-granite/granite-speech-5.0-470m-turboctc-nc: CC-BY-NC-SA licence, and Granite 5.0 is rejected in `model-trials.md`.
- LiquidAI/LFM2.5-24B-A2B and MiniCPM5-2B: no clean-up or normalisation score published; 24B does not fit beside the app.
